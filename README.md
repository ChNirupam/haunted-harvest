## Project

The Haunted Harvest is a responsive, three-chapter Halloween environment created with **HTML5 and CSS3 only**. No JavaScript is included.

### Chapters

1. **Haunted Halloween Town Square** — trick-or-treaters, bats, witch, black cat, fog, pumpkins, glowing house, moving hearse and falling candy.
2. **Midnight Graveyard Stroll** — walking visitors, black cat, owl, cyclist, drifting fog, swaying trees, ghost orbs and hover/focus gravestone ghosts.
3. **Cursed Beach Cove** — skeleton pirates, bonfire, bats, storm clouds, lightning, waves, ghost ship, crab and floating lanterns.

## Technical requirements demonstrated

- One external stylesheet: `haunted-harvest.css`
- CSS variables using the required Halloween palette
- Minimum 3 distinct scenes with CSS `:target` navigation
- `:hover` and `:focus-visible` interactions
- Multiple `@keyframes` animations
- Responsive layouts and mobile breakpoints
- Semantic HTML5 structure
- Keyboard-accessible navigation and focus states
- `prefers-reduced-motion` support
- No JavaScript
